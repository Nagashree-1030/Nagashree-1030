## 🐛 AutoBug Analyzer Engine

An engineering solution designed to reduce the time required to analyze and resolve software bugs.

### Problem

The traditional bug investigation process could require approximately **26 days of engineering effort**.

### Solution

Built a workflow connecting Jira, GitHub, and cloud infrastructure to analyze bugs, tickets, attachments, and source code.

```text
Jira Ticket
     │
     ▼
Ticket Analysis
     │
     ▼
Attachment Analysis
     │
     ▼
GitHub Code Comparison
     │
     ▼
Bug Identification
     │
     ▼
Suggested Resolution
```

### Result

The workflow reduced the analysis process from **weeks of engineering effort to minutes**.

**Technology**

`Jira` `GitHub API` `GCP` `Python` `AI`
